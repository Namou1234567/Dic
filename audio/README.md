# 中文词库配音

公共词库共 1652 条，按中文内容去重为 1474 段。由 Kokoro-82M-v1.1-zh 的 zf_001 普通话女声生成，语速 0.95。不是苹果系统声音或真人录音。

模型：https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh
项目：https://github.com/hexgrad/kokoro
模型声明 Apache-2.0 许可。音频在本地生成，不依赖浏览器系统中文语音。

每 50 段组成一个 MP3，片段间有 0.7 秒静音；manifest.js 将原中文词语映射到文件和起止时间。浏览器通过用户点击播放所选片段，时间边界会停止，防止继续读下一词。文件按需加载，不自动播放。个人新增、修改后不在清单的词语仍尝试系统朗读。

词义中的斜线读作停顿，括号补充说明不朗读。词库和学习进度结构未改动。
